### Week 3 Objectives:

* Learn the fundamentals and practical use cases of Amazon EC2.
* Understand core EC2 components such as Key Pair, Security Group, Elastic IP, User Data, and Amazon EBS.
* Practice launching and connecting to EC2 instances inside a VPC.
* Practice managing storage with Amazon EBS.
* Complete EC2 labs and consolidate foundational knowledge.

### Week 3 Outcomes:

* Understood the Amazon EC2 overview, common use cases, and basic instance types.
* Understood the role of Key Pair, Security Group, Elastic IP, User Data, and Amazon EBS in EC2 deployment.
