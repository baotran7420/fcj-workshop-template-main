## Mục tiêu

Chuẩn bị các công cụ cần thiết phục vụ quá trình phát triển, cấu hình và triển khai **AI Learning Assistant Platform** trên AWS.

---

## Nội dung thực hiện

Trong quá trình triển khai hệ thống, người thực hiện cần sử dụng một số công cụ hỗ trợ để quản lý mã nguồn, cấu hình máy chủ và kiểm thử ứng dụng.

Các công cụ được sử dụng trong workshop bao gồm:

| Công cụ | Mục đích sử dụng |
|----------|------------------|
| Git | Clone mã nguồn dự án từ GitHub Repository. |
| Visual Studio Code | Chỉnh sửa mã nguồn và các file cấu hình trong quá trình triển khai. |
| SSH Client | Kết nối đến máy chủ Amazon EC2 thông qua giao thức SSH. |
| Docker Desktop (Tùy chọn) | Kiểm thử ứng dụng trên môi trường local trước khi triển khai lên AWS. |

Đối với SSH Client:

- Trên Windows có thể sử dụng PowerShell/OpenSSH, PuTTY hoặc MobaXterm.
- Trên macOS/Linux có thể sử dụng Terminal tích hợp sẵn.

Sau khi cài đặt, cần kiểm tra phiên bản của các công cụ để đảm bảo môi trường làm việc đã sẵn sàng.
