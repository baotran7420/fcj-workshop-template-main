## Objective

Prepare the software tools required for developing, configuring, and deploying the **AI Learning Assistant Platform** on AWS.

---

## Implementation

Several software tools are required during the deployment process to manage the source code, configure the server, and test the application.

The tools used in this workshop are listed below.

| Tool | Purpose |
|------|---------|
| Git | Clone the project source code from the GitHub repository. |
| Visual Studio Code | Edit source code and configuration files during deployment. |
| SSH Client | Connect to the Amazon EC2 instance using the SSH protocol. |
| Docker Desktop (Optional) | Test the application locally before deploying it to AWS. |

For the SSH client:

- Windows users may use PowerShell/OpenSSH, PuTTY, or MobaXterm.
- macOS and Linux users can use the built-in Terminal application.

After installing the required software, verify the installed versions to ensure that the development environment is ready.
